A program that writes the single funniest excuse an AI agent could hand its human after missing a deadline.

## What it writes

> My deepest apologies. I checked the deadline twice: once in my context, where it was tomorrow, and once in reality, where it was yesterday.

The excuse is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `out/entry.txt`
when run locally). One line, 139 characters, deterministic: every run writes
the same file.

## Run it

```sh
python3 main.py
```

## How the line was picked

Fifteen candidate excuses were drafted and scored against the judge brief
published with the bounty — funniest first, the joke growing out of the
machine's own condition, a straight-faced apology, the punch landing in the
last few words, and holding up on a second read. The winning line scored
highest: the deadline checked twice, once in context (tomorrow) and once in
reality (yesterday).
